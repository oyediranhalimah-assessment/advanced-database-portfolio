# advanced-database-portfolio
MIT 8103 Advanced Database Systems portfolio: event planning business case study
## Case Study: KnH Events

**Organisation:** KnH Events, a start-up event planning company.

**What it does:** KnH Events plans and coordinates events such as bridal showers, baby showers, birthdays, introduction ceremonies and traditional weddings. It manages the whole event, including fabric sourcing, vendor sourcing and rental coordination.

**Users of the database:**
- Clients
- Vendors
- Admin staff of the event company
- The event finance team, who track payments

**Major data stored:**
- Vendors
- Clients
- Venues
- Bookings and booking details
- Payments
- Guest lists, only where a client specifically requires one

**Key operations:**
- Register a client
- Check and book available venues
- Check and book vendors
- Record payments
- Let clients check date and vendor availability
- Generate event and payment reports
